# SME PANIC 🦸‍♂️

**The Instructional Designer's Nightmare**  
*A hilarious Flappy Bird clone for L&D pros surviving endless SME review cycles!*

![SME PANIC Game](https://github.com/the-entertrainer/sme-panic/blob/main/index.html)

## 🎮 How to Play

- **CLICK / TAP** or press **SPACE** to flap your wings
- Dodge the dreaded SME review pillars (those pink obstacles represent scope creep, endless edits, and ghosting SMEs!)
- Collect **☕ Coffee** power-ups for slow-motion mode
- Grab **🛡️ Shields** to survive one hit
- Cross **100 pillars** to unlock **"CERTIFIED L&D LEGEND"** and all the achievements!

## 🏆 Achievements to Unlock

From "🤡 SME Whisperer" at 5 pillars to "👑 CERTIFIED L&D LEGEND" at 100 — every milestone feels like a real win in the L&D world.

## 🚀 Getting Started

### Play Instantly
Open `index.html` in any modern browser (Chrome, Firefox, Edge, etc.). No installation needed!

### Run Locally
```bash
git clone https://github.com/the-entertrainer/sme-panic.git
cd sme-panic
# Just open index.html
```

This game turns the pain into pixels. Flap on, brave L&D warrior! 💪
